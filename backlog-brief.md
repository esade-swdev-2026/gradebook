# Product backlog

|N|Item|Notes|
|-|----|-----|
|1|As a teacher, I can log in with my username, so that I get access to my own workspace||
|2|As a teacher, I can add/edit/remove students from my class, so I can manage my class||
|3|As a teacher, I can record a students grade, by checking the name and adding the number, so that I can keep track||
|4|As a teacher, I can update a students grade, by checking the name and adding the number, so that I can keep track||
|5|As a teacher, I can assign different weights to each assignment, so that they contribute differently to the final grade||
|6|As a teacher, I can forecast/calculate their final grade, so that I know the minimum grades they should get to pass my course||
|7|As a teacher, I can see the statistics (averages) of students, so I can keep track of the overall performance||
|8|As a teacher, I can see my students' current final grade for each course and overall gpa, so that I can see their academic performance||

# Definition of Done

- The CI check is green
- There is at least one test for each new feature
- Errors such as invalid input are caught and print a message
